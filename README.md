# Shadow-Kedi
Open-source Shadow IT detection, insider threat and AI data leakage platform for Small to Medium size businesses

🎯 What It Does
- Detects unauthorized SaaS and AI tool usage
- Monitors insider threats and data exfiltration
- Scores user risk in real-time (0-100)
- Provides explainable alerts and dashboards
